# HorizonTechX_Python-Internship
#About
Completed a 1-month Python Programming Internship at **Horizon TechX**.
Worked on 2 core Python projects to strengthen problem-solving and logical thinking skills.

# Tasks & Projects

# 1. Hangman Game - `hangman.py`
Description: A console-based word guessing game where the player guesses letters to find the hidden word.
Key Features:
- Random word selection
- Limited attempts with visual feedback
- Input validation and score tracking
Concepts Used: Loops, Conditionals, Lists, String Manipulation, Functions

# 2. Chatbot - `chatbot.py`  
Description : A simple rule-based chatbot that responds to user inputs with predefined answers.
Key Features :
- Interactive conversation with user
- Responds to: `hello`, `hi`, `how are you`, `your name`
- `help` command to show all available commands
- `bye` command to exit the chat
- Handles unknown inputs with default message
Concepts Used : Conditional Statements, String Handling, User Input, While Loop.
